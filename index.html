How do I get my Firebase config? (click to expand)
  1. Go to console.firebase.google.com
  2. Click Add project → name it "hangout-hq" → Create
  3. Click the </> (Web) icon to add a web app
  4. Register the app, then copy the firebaseConfig object
  5. In your Firebase project, go to Build → Realtime Database → Create database → Start in test mode
  6. Paste the entire config object below

Your config is saved in your browser. Share the site URL with friends — they'll need their own config too, or you can bake it into the code.
